# 셀렉상회 판매글 메이커

후르츠패밀리와 당근마켓 판매글 작성을 위한 셀렉상회 전용 웹앱입니다.

- 상품 검색 및 자동완성
- 엑셀·Google 스프레드시트 상품 불러오기
- 의류 종류별 실측 입력
- 판매글 자동 생성 및 복사
- 저장 상품 목차, 검색, 수정, 삭제
- 관리용 판매 가격 저장

GitHub Pages에서 동작하며 Supabase 로그인 후 저장 상품과 불러온 상품 목록을 여러 기기에서 동기화할 수 있습니다. 로그인하지 않은 경우에는 사용 중인 브라우저에만 저장됩니다.

## Supabase 설정

Supabase SQL Editor에서 `supabase-setup.sql`을 실행하면 사용자별 판매글 및 상품 목록 테이블과 Row Level Security 정책이 생성됩니다.
# 번개장터 등록파일

상품 목차의 **번개장터 일괄등록**에서 수정일과 기존 검색 조건으로 상품을 선택하고, **등록파일 준비**에서 성별·카테고리·가격·사이즈·사진을 확인합니다. 최대 50개 상품, 상품별 12장·합계 500장 이내 사진을 한 ZIP으로 내려받습니다. ZIP에는 공식 번개장터 양식의 엑셀, 순서대로 이름을 붙인 사진 폴더, 등록 안내가 들어 있습니다.

기존 상품은 저장된 대표사진 한 장으로 시작합니다. **사진 관리**에서 상세사진을 추가·교체·정렬하고 저장하면 이후 내보내기에도 재사용됩니다. 상품 목차의 대표사진은 그대로 유지됩니다. 사진이 없거나 필수 정보가 빠진 상품은 파일 생성 전에 확인 메시지가 나옵니다. 기본 카테고리 성별은 남성이므로 여성용 상품은 반드시 변경해 주세요. 목록에 없는 카테고리는 판매자센터에서 확인한 ID를 직접 입력할 수 있습니다.

파일 준비는 실제 상품 등록이 아닙니다. 판매자센터에 엑셀과 사진을 업로드하고 등록 요청이 성공하면 **등록 요청을 마쳤어요**를 눌러 목차에서 등록대기로 관리합니다. 실제 판매글이 생성된 후 기존 **번개장터 업로드 완료**를 체크합니다. 준비·대기 정보와 사진은 로그인한 계정의 기존 상품 데이터에 함께 보관되며, 별도 외부 서버나 AI 호출은 사용하지 않습니다.
